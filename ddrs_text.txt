User registration 
Process Flow 
User visits DDRS portal → Clicks 'New Registration'
Selects User Type (Manufacturer / Importer / CRO / Ethics Committee / Lab / Distributor)
Fills Registration Form – Organisation Details → Authorised Signatory → Verification → Set Password
Mobile OTP (6-digit, valid 5 mins) + Email OTP (valid 15 mins) verified
On successful verification → System generates unique User ID (format: DDRS/YYYY/XXXXXXXX) and sends login credentials

Drug License Application – Form 40 (Registration Certificate)
Form 40 is used to apply for a Registration Certificate (RC) for new drugs, biologics, vaccines, medical devices, and cosmetics. Three case types are supported: Fresh, Endorsement, and Re-registration. Endorsement / Re-registration require prior RC details entered in Historical Data before accessing Form 40.
Application Case Types
Fresh: First-time application for RC for a product not previously registered in India.
Endorsement: Addition of new strength, new presentation, or new indication to an existing RC. Requires existing RC Number to be entered first in Permission Owned / Historical Data.
Re-registration: Renewal of an expired RC. Requires previous RC Number and expiry date in Historical Data.

Inspection & Approval Process
Application Submitted → ARN Generated → Officer Assignment (CDSCO)
Document Scrutiny (Preliminary Check) → Deficiency Letter if incomplete
Applicant Response / Resubmission within deadline
Technical Scrutiny (Subject Expert Committee / Division Head)
Site Inspection Scheduled (if required) → Geotagged inspection with Form 35 / MD-11 checklist
Inspection Report submitted by Drug Inspector (digitally signed)
Expert Committee Review (SEC / NDAC meeting) if applicable
Decision: Approved (Form 41 / Form 10 issued) → RC / License delivered to DigiLocker + portal
Decision: Rejected → Rejection order issued; appeal option enabled for applicant

Application Status & Applicant Dashboard
Applicants can view all submitted, draft, approved and rejected applications from a central dashboard. Real-time status updates are provided via portal, SMS, and email at every stage transition.
Status
Description
Next Action
DRAFT
Application saved but not submitted; auto-expires in 90 days
Applicant completes and submits
SUBMITTED
Application submitted to CDSCO; awaiting officer assignment
CDSCO assigns scrutiny officer
UNDER REVIEW
Documents being scrutinized by CDSCO officer / division
Officer raises deficiency or advances
DEFICIENCY RAISED
CDSCO raised deficiency; applicant must respond within deadline
Applicant uploads additional documents
INSPECTION SCHEDULED
Site inspection scheduled; applicant informed of date and team
Inspection carried out; report submitted
SEC REVIEW
Application referred to Subject Expert Committee / NDAC
Committee meeting outcome recorded
APPROVED
RC / License issued; available in Digi Locker and portal
Applicant downloads license document
REJECTED
Application rejected; reason communicated; appeal option available
Applicant may file appeal or fresh application
Notification Triggers
SMS + Email on: Application Submitted (ARN generated), Deficiency Raised (with deadline), Inspection Scheduled (with date and officer), SEC Review Scheduled, Application Approved (with RC/License number), Application Rejected (with reason code).
In-app notifications visible on applicant dashboard with timestamp and action button.
License / RC delivered to applicant's DigiLocker vault on approval.
